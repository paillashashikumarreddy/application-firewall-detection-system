APPLICATION LEVEL FIREWALL (WINDOWS)
==================================

Execution Steps:
1. Install Python 3.9+
2. Extract this ZIP
3. Open CMD in this folder
4. pip install -r requirements.txt
5. python app.py
6. Open http://127.0.0.1:5000
